This is groundwork for parsing the partner's daily feed, which is the next task. The partner sent us this description of their feed format version 3, so you have it for then: the first line is a header `#FEED v3 <n>` where `<n>` is the number of data lines; any other version is unusable. Each data line is `id|ddmmyyyy|amount|currency|crc`, with the date as day, month, year without separators, and the amount an integer in minor units with two implied decimals (`12345` is 123.45, and a leading `-` means a negative amount). `crc` is the CRC32 of the line's text before the final `|`, written as exactly 8 lowercase hex digits. Rows with a wrong checksum are dropped and counted, they don't fail the feed, but a header count that doesn't match the number of data lines does.
